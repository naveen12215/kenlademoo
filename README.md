# Kenla Systems

Marketing site for Kenla Systems — Next.js 16, React 19, Tailwind CSS v4.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run build
npm start
npm run lint
```

Content lives in `src/data/`. Brand tokens live in `src/app/globals.css`.
